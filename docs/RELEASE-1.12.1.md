# 斐墨 1.12.1

- 修复工作台点击新建日程后空白：移除旧编辑器隐藏新版共享卡片的样式。工作台与悬浮卡片均可完整新增、编辑和保存。
- 日视图左上角新增“返回月视图”。编辑/新建的保存、删除操作置于右上角，滚动时保持可见。
- 颜色选择改为卡片内调色板与十六进制输入，避免系统颜色窗口触发悬浮工具收起；已有输入和页面状态保持。

- 提交规划后提示“收到，正在规划中...✍️”，完成后提示“已帮你规划完成✅”。任务在主进程继续，关闭日程页面不取消；再次打开可查看后台忙碌状态并停止任务。

完整保留实时语音、长回答播放修复、公式渲染、日历规划和高级计算器。验证使用虚构日程、完整工作台样式、隐藏安装程序窗口与隔离配置，不操作真实麦克风或剪贴板。
