# 1.10.2 · 平滑过渡与结构化截图结果

- 胶囊与顶部精灵的过渡使用稳定的窗口裁剪区域，移除移动子区域的逐帧重复裁剪，隐藏过渡中的后台卡片，胶囊底纹保持透明与圆角。
