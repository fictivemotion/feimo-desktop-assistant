# 斐墨 1.11.0

- 单击顶部精灵进入胶囊，双击（或聚焦后 F2）开始实时语音对话；悬停不再自动进入胶囊。
- 接入千问 AI 平台 `qwen-audio-3.1-realtime-plus`，使用 `wss://maas.qianwenaiapi.com/api-ws/v1/realtime`，不需要填写工作空间。设置 → 模型 → 实时语音对话可选择 13 个系统音色，修改在下次对话生效。
- 使用 `smart_turn` 判断有效语音轮次，环境声与无意义附和不触发回答；确认插话后立即清空旧音频，丢弃迟到响应。持续保持一个麦克风和一个 PCM 播放队列，不重复调用 TTS。
- 浏览器回声消除与降噪保持开启，自动增益关闭；语音对话期间暂停助手白噪音，结束后恢复，不修改系统总音量或麦克风增益。锁屏、休眠、连接错误和退出时释放音频。
- 语音模式形象佩戴头戴式麦克风耳机，所有状态均不戴眼镜。倾听时点头，推理时思考，回复时沿用打字动作并保持耳机形象。
- 初始气泡“天才斐墨，为您服务🌹”，ASR 与回答单行流式滚动。助手回答可展开为完整卡片；回复气泡空闲 10 秒自动收起，展开的阅读卡片保留，直到手动关闭。
- 播报完毕后 20 秒没有继续发言则结束；结束文案“下班了886👋”。仍在阅读的卡片不因结束或提示过期而消失。
- 原有语音听写与对话互斥，保留输入目标、剪贴板回退和语音快捷键。对话密钥单独加密保存，未设置时复用已有千问听写密钥；公开包不携带维护者密钥。

## 验证与边界

通过模拟会话/回合测试、现有回归测试及 1000/620 px 后台 UI 检查。千问真实接口已用合成问题音频验证输入 ASR、回复文字与 PCM 音频，无真实麦克风采集或扬声器播放。不同声卡、耳机、扬声器和虚拟设备的回声表现仍需实际使用反馈。

协议与音色依据：[千问实时语音对话](https://platform.qianwenai.com/docs/developer-guides/speech/qwen-audio-realtime)、[模型说明](https://www.qianwenai.com/models/qwen-audio-3.1-realtime-plus)。
