# 隐私说明

斐墨是本地运行的桌面程序，没有斐墨自有账号或云端同步服务。

## 本地数据

应用设置、日程、问答历史、倒计时记录和 Token 用量存放于 Windows 用户数据目录 `%APPDATA%\桌面宠物助手\`。模型 API 密钥与 Notion Token 通过 Electron `safeStorage` 加密后保存在本机。工具箱中的剪贴板、速记与收藏色卡同样通过 Windows DPAPI 加密保存在 `toolbox.bin` 中；不会自动同步到外部服务。此目录名保持稳定，应用更名为斐墨后也会继续读取原有设置。

## 外部连接

- **剪贴板与 OCR：**默认只在用户主动使用快捷键或工作栏时读取。开启工具箱中的“自动记录剪贴板”后，会后台读取并保存文字与图片；关闭后停止后台采集。最多保留 80 条记录，固定项最多 20 条，过大内容不收录，常见密钥格式会过滤（并非完整的敏感内容识别）。图片识别由 Windows OCR 在本机完成。
- **AI 问答与润色：**仅在用户明确发送请求时，将所选文本发送至用户配置的模型服务商。服务商如何保留请求内容，以其隐私政策为准。
- **Coding Agent 监控与用量：**只读本地会话与用量日志，不上传这些文件。
- **Notion：**可选只读同步。Token 保存在本机，日程数据读取自用户明确连接的数据库。
- **遥测：**应用本身不发送分析或遥测事件。

## 公开仓库与发行包

公开仓库不收录本机 `.agents/`、`_shots/`、应用运行数据或密钥。仓库中的伊埃斯同人复刻素材独立采用 `assets/pets/eous/LICENSE.txt` 所列的非商业许可；源码 MIT 许可不适用于这些素材。提交前仍请检查新增文件和 Git 历史；`.gitignore` 只能阻止后续误加，不能从已有提交中抹除凭据。
