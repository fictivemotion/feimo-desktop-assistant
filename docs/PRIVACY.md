# 隐私说明

斐墨是本地运行的桌面程序，没有斐墨自有账号或云端同步服务。

## 本地数据

应用设置、日程、问答历史和 Token 用量存放于 Windows 用户数据目录 `%APPDATA%\桌面宠物助手\`。模型 API 密钥与 Notion Token 通过 Electron `safeStorage` 加密后保存在本机。此目录名保持稳定，应用更名为斐墨后也会继续读取原有设置。

## 外部连接

- **剪贴板与 OCR：**只在用户主动使用快捷键或工作栏时读取。图片识别由 Windows OCR 在本机完成。
- **AI 问答与润色：**仅在用户明确发送请求时，将所选文本发送至用户配置的模型服务商。服务商如何保留请求内容，以其隐私政策为准。
- **Coding Agent 监控与用量：**只读本地会话与用量日志，不上传这些文件。
- **Notion：**可选只读同步。Token 保存在本机，日程数据读取自用户明确连接的数据库。
- **遥测：**应用本身不发送分析或遥测事件。

## 公开仓库与发行包

公开仓库不收录本机 `.agents/`、`_shots/`、个人宠物素材、应用运行数据或密钥。提交前仍请检查新增文件和 Git 历史；`.gitignore` 只能阻止后续误加，不能从已有提交中抹除凭据。
