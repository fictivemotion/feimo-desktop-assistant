# 隐私说明

斐墨是本地运行的桌面程序，没有斐墨自有账号。

## 本地数据

1.5.0 起的公开版将应用设置、日程、问答历史、倒计时记录和 Token 用量存放于 `%APPDATA%\斐墨助手\`，不读取私人版的原用户数据目录。模型 API 密钥与 Notion Token 通过 Electron `safeStorage` 加密后保存在本机。工具箱中的剪贴板、速记与收藏色卡同样通过 Windows DPAPI 加密保存在 `toolbox.bin` 中；不会自动同步到外部服务。首次使用此公开版需要自行配置可选服务。

## 外部连接

- **剪贴板与 OCR：**默认只在用户主动使用快捷键或工作栏时读取。开启工具箱中的“自动记录剪贴板”后，会后台读取并保存文字与图片；关闭后停止后台采集。最多保留 80 条记录，固定项最多 20 条，过大内容不收录，常见密钥格式会过滤（并非完整的敏感内容识别）。图片识别由 Windows OCR 在本机完成。
- **AI 文字清洗：**按下文字 / 图片清洗快捷键、点击工作台清洗或载入图片识别后，将原文 / 识别正文发送至 DeepSeek V4.1 Flash（非思考模式），用于格式清洗和内容校对；图片本身不发送。清洗请求不在输入过程中自动触发，原文保留，结果完整返回后才能复制。清洗密钥本机加密保存，也可复用已配置的官方 DeepSeek 密钥。
- **AI 问答与润色：**仅在用户明确发送请求时，将所选文本发送至用户配置的模型服务商。服务商如何保留请求内容，以其隐私政策为准。
- **Coding Agent 监控与用量：**只读本地会话与用量日志，不上传这些文件。可选会话桥接在明确预览安装后写入本机 Hooks 配置，仅通过本机认证命名管道接收事件和用户批准 / 问题回复；不会自动同意未授权操作。原始工具输入只在当前进程内保留。
- **Notion：**可选只读同步。Token 保存在本机，日程数据读取自用户明确连接的数据库。
- **在线白噪音：**从 Moodist 的公开 GitHub 素材加载音源，无需账号；播放与音量偏好留在本机。
- **赞赏：**设置和 README 展示开发者明确提供的收款码。仅用户自愿在支付 App 扫码时发生支付；斐墨不读取付款信息、不验证金额，也不关联功能解锁。
- **语音听写：**仅在快捷键开启后请求麦克风，结束、取消、锁屏或退出会释放录音。离线模式在本机识别；Qwen / 其他在线模式会发送本次音频到用户选择的服务。AI 校对发送本次正文、热词和提示词，不发送输入框前后文。录音与听写不写入历史文件，本次结果仅在进程内保留；完成后按用户操作自动复制到剪贴板。独立 API 密钥使用 DPAPI 加密。热词、角色和非密钥接口设置为本地普通设置。
- **语音统计与快捷键：**`voice-stats.json` 仅保存每日字数、音频时长、完成次数及用于去重的随机会话 ID，不含正文或音频。统计不会纳入其他输入法。选择 Ctrl+Alt 时启用 Windows 键盘钩子，只判断该组合是否按下、是否混入其他键以及松开时机；事件继续传给系统，不记录普通按键内容，不拦截或替换其他输入法。选择带普通键的组合时关闭该钩子，使用系统快捷键注册。
- **遥测：**应用本身不发送分析或遥测事件。

- **服务连接：**GitHub、Notion、Stripe、n8n、Vercel、Resend、Cal.com 仅在启用后轮询用户授权的服务。凭据经 DPAPI 加密，不传给渲染窗口；Notion 可复用日程 Token。断开 Notion 卡片保留日程所用 Token。
- **音乐：**优先使用本机 Windows 媒体会话。网易云 3.x 兼容读取 cloudmusic 窗口标题、音频状态及播放时钟：只以查询和读取权限读取匹配到的 8 字节时间值，不注入 DLL、不写入播放器内存、不读取账号或 Cookie。识别失败时回退到明确标注的估算。主动拖动进度条会在完整播放器窗口操作进度条，短暂显示播放器并恢复原窗口和鼠标位置；不支持的布局明确报错。歌词查询仅向网易云发送当前曲名与歌手。
- **文件库：**拖入文件会复制到本机文件库，原件保留。分类向 DeepSeek 发送名称、类型与有限提取内容（文字 / PDF / DOCX / 本机 OCR），不上传完整二进制文件。文件副本与分类索引未加密，待选择副本可重启恢复。问答中主动 @选择文件时，有限正文片段会发给已配置的问答模型。拖出文件仅启动系统附件拖放，不发送消息。
