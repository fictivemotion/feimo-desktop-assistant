# 外部文件夹引用

在工作台或桌面文件库选择“引入文件夹”，选择已有资料目录。文件库首页引入时创建引用项目；在本地项目内引入时成为该项目下的引用文件夹。目录和文件留在原位置，不再复制到文件库。引用会随应用重启恢复。

点击引用文件夹逐层浏览，支持当前目录名称检索、上一级、刷新和原位置定位；工作台还保留原有拖出操作。外部新增、修改、删除文件后刷新显示，不递归扫描整个磁盘。

“移除引用”只从文件库移除入口，原目录和文件全部保留。原磁盘断开或目录移动时保留入口并提示暂不可用，重新连接后可以刷新。引用目录由原文件夹管理，不作为复制归档目的地；新建本地项目、原有导入、网页剪藏和内容提问仍可继续使用。

外部资料不会自动发送给模型。已浏览文件可按名称检索；显式提及外部文本文件时读取原文件的有限正文，复杂格式未自动提取时会保留未读取正文的说明。内容和引用索引不复制进他人的版本包。

实现边界：最多64个引用；每次只读当前目录最多1500项，不跟随越出引用根的链接，拒绝路径穿越与Windows数据流路径。原路径只保存在本机文件库index.json，发送给界面的目录信息不带原绝对路径；动态文件ID必须在当前有效引用下重新解析。解除引用后旧ID失效。
