# 1.10.6

## 开机启动

新安装首次运行默认开启 Windows 登录自启动；已有用户明确关闭的设置保留。设置页显示实际系统注册状态，随时可关闭。

## 语音音量恢复

旧版只保存静音开关，录音期间音量发生变化后无法还原百分比。现在同时记录输出设备、应用音频会话和可读取的麦克风原始音量；轮询不会覆盖第一次快照。恢复时先还原音量，再解除原本未静音的输出，原先已静音的设备仍保持静音。

麦克风停止和音频图挂起后确认释放，再恢复输出；暂停会释放输入源，继续时重新获取，避免暂停期间仍持有录音设备。快速暂停 / 继续按顺序恢复和重新隔离。取消准备中的麦克风获取会关闭迟到的输入流，停止确认最长等待 750 毫秒，避免界面卡住。

关闭浏览器自动增益，保留麦克风降噪与必要的回声消除。客户端关闭时原生租约仍负责恢复，兼顾父进程退出。

## 验证

208 项功能测试通过。原生回归使用虚拟端点验证从 6% 恢复到开始前的值、应用音量、麦克风增益、原始静音状态、快照保留与恢复失败重试；未改动用户当前真实设备音量。另验证源停止确认、准备期间取消、暂停重启和快速暂停 / 继续顺序。
