# 桌面卡片

在「设置 → 桌面卡片」选择日历日程、重要级待办、文件库、速记或问答。托盘右键也可创建、显示、隐藏和管理卡片；每种类型只有一张，重复创建会显示已有卡片。

卡片标题栏可拖动，右下角手柄或窗口边缘可调整大小。标题栏减号收起、加号展开，齿轮打开当前卡片设置；卡片右上角不设删除按钮。管理页可再次显示或移除；移除仅删除卡片布局，不删除日程、文件或速记。退出和重启保存布局，显示器变更时恢复到可见区域。

日历提供月/周/日视图和现有完整日程编辑与规划。月视图使用日期、事项数量与颜色点概览，下方完整列出选中日期的事项；选择时间表进入日视图。周视图在宽卡片中显示七列小时安排，窄卡片中显示七天的完整时间与事项列表。待办按十字四象限显示：紧急级为重要且紧急，重要级为重要不紧急，普通事项在24小时内开始时视为紧急，其余为普通不紧急。可显示今天或未来7/30/90天，并在本机标记已完成的具体日程实例。完成不会删除日程或更改远端账号内容。文件库首页复用工作台的项目文件夹形象，进入项目后可选子文件夹、按文件名检索，点击文件在资源管理器中定位；速记可新增、阅读、编辑、删除，共用原有加密记录。

材质参考 [DeskBox](https://github.com/Tianyu199509/DeskBox) 的公开选项，斐墨独立实现，未引入该项目的源码或素材。保留斐墨字体、图标与无外阴影表面：

| 材质 | 效果 |
| --- | --- |
| 透明 | 可调透明底色；不透明度0时只留文字与控件 |
| 云母 | Windows壁纸取景的系统云母 |
| 云母 Alt | 更明显的层次，使用系统Tabbed背景 |
| 轻薄亚克力 | 系统亚克力和较轻着色 |
| 基础亚克力 | 同一系统亚克力叠加更厚实的基底着色 |
| 纯色 | 无磨砂的平面背景，初选时不透明度为100% |

不透明度只作用于背景，文字保持清晰；材质浓度独立控制着色与纹理。Windows 11 22H2及以上使用Electron提供的DWM系统背景；较旧系统或调用失败时显示兼容着色效果并提示。两个亚克力方案使用同一DWM亚克力，基底着色区分浓度，并非直接运行WinUI的DesktopAcrylicController。材质明暗通过只作用于当前卡片的DWM属性设置，跟随系统模式时也会更新，不修改其他窗口或Windows全局主题。

配置与完成标记保存在应用数据目录的desktop-widgets.json；不写入外部账号，也不复制文件库或速记正文。每种卡片仅暴露其需要的IPC方法，速记通知不传递剪贴板历史。

## 1.14.0 布局与胶囊

默认卡片圆角32px，可调0–48px；胶囊固定26px。首建卡片先初始化当前窗口的DWM明暗、圆角和无边框，再显示；透明材质同样初始化，不再依赖切换材质。旧默认20px布局迁移到32px。

卡片设置中选择“离开自动收起 · 悬停展开”，可设0.2–10秒收起延迟；标题中间悬停150ms展开，点击标题或加号也可展开，图标区保留拖动。默认手动，避免升级后突然收起。胶囊可设独立220–500px宽度或与展开卡片同宽，保存展开尺寸；设置、日程编辑/规划、新建菜单和速记未保存期间暂停自动收起。

打开“吸附”与“贴近卡片时自动组合”后，将卡片拖到另一张边缘，松开即可纵向或横向组合。同组等宽、间距8px；拖动任何成员带动整组，调整宽度联动其他成员。纵向组合空间不足时在不低于260px的前提下分配高度，放不下则保留独立卡片。组内胶囊保持等宽。卡片设置可“移出组合”，关闭自动组合、隐藏或锁定成员也会将其移出。布局与组顺序在同一笔原子写入后恢复。

设置→桌面卡片中的“自动对齐与组合”会把当前显示且未锁定的卡片按屏幕排列成等宽行组。锁定卡片保留原位，空间不足或与锁定卡片冲突时提示，不覆盖锁定布局。大幅改变显示器配置后可用此入口重新整理。

交互参考：[DeskBox胶囊模式](https://github.com/Tianyu199509/DeskBox/blob/main/docs/articles/09-capsule-mode.md)、[外观与交互](https://github.com/Tianyu199509/DeskBox/blob/main/docs/articles/12-appearance-and-interaction.md)。本实现的组合为多个可同时查看的独立卡片排列，不是DeskBox在同一表面切换成员的格子组；未复制其源码。

## 1.15.0 贴边、避让与文件夹引用

将卡片拖到显示器左侧或右侧18px以内，松开自动吸附成只含图标和名称的大圆角胶囊。点击胶囊展开，右侧胶囊向左展开，左侧向右展开；减号或已开启的自动收起可返回胶囊。吸附胶囊使用点击展开，鼠标经过不会突然打开。拖动图标离开侧边或在卡片设置中“取消侧边吸附”可恢复自由摆放；可关闭“左右贴边自动收为吸附胶囊”。锁定卡片不自动移动。

胶囊展开时，周围卡片在屏幕可用区域临时避让，收起后返回原排列。位置分为保存的锚点与临时展示位置，避让不写入锚点；组内胶囊也可以使用独立紧凑宽度。空间极端不足时，挡住的胶囊暂时让出显示空间，收起后恢复。移动或缩放回执不应误判为手动拖动而改变锚点。

亚克力采用当前卡片的Composition Accent层，关闭系统临时窗口背景的失焦灰白回退；透明度与浓度仍由原有控件设置。云母继续使用DWM壁纸背景。材质助手失败可重新启动，焦点切换、唤醒及定期检查会重新申请原生效果，迟到结果不能覆盖新选择；临时失败仅使用同等透明着色。恢复材质不重排窗口或重建正在输入的设置表单。不更改Windows全局透明度、主题或焦点。Win32接口不可用时仍会显示兼容外观；支持平台的原生调用已在隔离隐藏窗口验证。

文件库卡片设置可调整32–200px文件夹图标与立体／简洁样式；小尺寸使用不带重复文字的文件夹形象。工作台和卡片“引入文件夹”将原位置作为项目或当前本地项目的子文件夹引用，不复制内容。具体说明见[外部文件夹引用](FILE-REFERENCES.md)。

## 问答卡片（1.22.0）

在设置或托盘创建「问答」，选择模型后输入并发送。DeepSeek 使用 AI 文字清洗 / 现有 DeepSeek 配置的密钥；千问使用语音对话中配置的千问 AI 平台密钥。两种模型均提供思考开关。

拖入、点击添加附件或 Ctrl+V 粘贴文件图片；发送前可以移除附件。支持图片、UTF-8 文本、PDF（前四页）和 Word（提取内容有范围提示），不支持的格式不会假装已读取。单个附件最多20MB，每条最多6个；附件内容只在点击发送后传给所选模型。

Codex 模型来自本机已安装并登录的 Codex CLI / Codex 桌面程序，以实时返回的模型与思考强度为准。连接只用于文字和图片问答，不开放命令、MCP、插件和文件修改。不会操作 ChatGPT 网页或导入其网页登录凭据；Codex 用量按当前登录账号计算。

「历史」显示卡片会话；「导入 Codex」分页加载 Codex 本机历史，点击导入文字副本后可以在卡片中继续问答，不改原会话。历史与附件使用本机加密服务按会话存储，不随安装包发送；可删除单段会话。遵循设置中的保存对话历史开关。读取一段对话与附件内容上限12MiB，单段100条消息、最多200段历史，达到上限会提示新建或清理。空闲60秒释放 CLI 进程，应用开机不会启动它。
