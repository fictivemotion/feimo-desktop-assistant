# 顶部精灵与消息

设置 → 常规 → 宠物形象 → 顶部精灵尺寸，支持 48–180 px，拖动后自动保存。

顶部模式有隐藏点、精灵、胶囊、工作台四态。语音、音乐 / 白噪音、提醒、结果会唤出精灵。

消息默认显示在精灵右侧的圆角气泡：高度按形象组件约 82% 缩紧并垂直居中，文字最多两行。长消息、问答或归档选择有右下角展开按钮，可打开完整卡片，支持收起、复制、关闭、分页。普通通知仅保留最新一条，只有问答堆叠多页。鼠标可直接进入气泡操作。

听音乐时，空闲气泡按真实进度显示当前句歌词，拖动歌曲进度直接跳转到对应句。提醒优先展示，关闭提醒后恢复歌词。关闭歌词气泡只隐藏当前歌曲的歌词，下首歌曲可重新显示。语音期间不展示歌词。

悬停精灵：同一个 Rive 实例在 320 ms 内移动并缩小到胶囊左侧，胶囊同时淡入；离开后反向恢复。胶囊保留歌词控制与快捷工具。工作台通过按钮展开。手动隐藏不会被持续状态的轮询重新打开。

语音时双手快速敲键盘，暂停时休息、校对时思考。Mochi 能量 / 弹泡 / 金币提示分别用于成功 / 展开及语音开始 / 文字整理和图片转译完成。提示音在采集前结束，采集中安静。

录音前必须收到白噪音播放器的实际暂停确认，再静音 Windows 输出；结束、取消、暂停录音时恢复。期间手动关闭的声音不会被自动重新打开。输出隔离成功时关闭软件回声消除的播放参考，降噪和电平处理保留。
