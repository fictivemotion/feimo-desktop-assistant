# 顶部精灵态

顶部模式现在有四种呈现：隐藏小点、精灵、胶囊、展开工作台。

- 语音输入、音乐 / 白噪音播放、主动通知、问答卡片或完成提示出现时，在顶部居中显示单个精灵。没有胶囊背景、文字栏和常驻按钮。
- 卡片紧接精灵下方，留 8 px 间距。普通通知仅保留最新一张；问答继续分页叠卡，支持选段、复制和关闭。
- 悬停精灵会恢复胶囊及快捷工具，只有点击工作台按钮才展开。鼠标离开交互区后回到精灵态；直接操作精灵下方的卡片不会强制切换胶囊。
- 正在使用工作台时，新状态不会把它收回。倒计时与 Coding 等已有胶囊状态仍可使用。
- 持续状态下手动收起会保持隐藏。新的语音会话、播放操作或新的通知可再次唤出；轮询不会反复打开。
- 精灵态可右键收起；胶囊保留向上箭头及上滑收起。

语音时使用 Rive `typing` 动作：双手快速交替敲键盘、身体轻微随动作起伏。暂停时休息，文字校对时思考，完成时显示完成动作。

音效采用 [Mochi UI Sounds](https://github.com/lyx404/Mochi-UI-Sounds) 的氛围配方：能量用于操作成功，弹泡用于工作台展开与语音开始，金币用于语音文字整理、文本清洗、图片转译完成。音量和开关位于设置 → 常规 → 伙伴提示音。

语音开始的弹泡在麦克风采集前播放。准备阶段最多等候 250 ms；音频不可用时直接跳过，避免阻塞听写。采集、暂停、结束与校对期间停止提示音，完成后恢复。敲键盘是视觉动作，采集中不循环播放敲击声。

提示音使用全应用唯一的 Web Audio 播放器，本地合成，无音频文件下载。重复事件有冷却，隐藏形象暂停渲染。上游来源见 `assets/vendor/mochi/UPSTREAM.md`。
