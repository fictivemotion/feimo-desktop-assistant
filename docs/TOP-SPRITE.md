# 顶部精灵与消息

设置 → 常规 → 顶部精灵 → 顶部精灵尺寸，支持 48–180 px，拖动后自动保存。助手仅保留顶部模式、斐墨 · Rive 形象。

顶部模式有隐藏点、精灵、胶囊、工作台四态。语音、音乐 / 白噪音、提醒、结果会唤出精灵。

消息默认显示在精灵右侧的圆角气泡：高度按形象组件约 82% 缩紧并垂直居中，宽度随文本长度调整，文字最多两行。长消息、问答或归档选择有右下角展开按钮。普通提醒和歌词不提供复制按钮；最右侧居中的 `<` 箭头向左收起气泡。问答完整卡片保留全文复制、分页与停止。

听音乐时，气泡按句显示歌词，尾部固定显示 🎶。SMTC 提供完整时间线时按系统进度同步；网易云未提供时间线时使用只读进度读取或估算。只有 SMTC 明确提供调节能力及有效时长时才显示进度条，不模拟鼠标拖动播放器。关闭歌词气泡只隐藏当前歌曲的歌词，下首歌曲可重新显示。

倒计时、歌词、语音、白噪音等并行活动堆叠显示，点击气泡轮换前台活动并切换对应 Rive 动作。普通通知仍只保留最新一条；问答继续按段落分页。倒计时在气泡内直接暂停、继续或结束。

悬停精灵：同一个 Rive 实例在 320 ms 内移动并缩小到胶囊左侧，胶囊同时淡入；离开后反向恢复。在胶囊外点击会立即返回精灵态；切歌保持精灵态。工作台通过按钮展开。手动隐藏不会被持续状态的轮询重新打开。

快捷工具第二项为翻译，使用 DeepSeek `deepseek-flash` 自动中英互译。启用后只翻译新复制的文字，译文直接写入剪贴板；新复制会取消旧请求，自身写入不会重复翻译。每个气泡右下角可退出翻译模式，退出会取消未完成请求。复用已配置的 DeepSeek 密钥，复制内容会发送到该接口。

设置只有一个页面，连接分类包含顶部活动、会话桥接、Music、GitHub 和 Notion；已移除 Cal.com、Resend、Vercel、n8n、Stripe。

语音时双手快速敲键盘，暂停时休息、校对时思考。Mochi 能量 / 弹泡 / 金币提示分别用于成功 / 展开及语音开始 / 文字整理和图片转译完成。提示音在采集前结束，采集中安静。

录音前必须收到白噪音播放器的实际暂停确认，再静音 Windows 输出；结束、取消、暂停录音时恢复。期间手动关闭的声音不会被自动重新打开。输出隔离成功时关闭软件回声消除的播放参考，降噪和电平处理保留。
