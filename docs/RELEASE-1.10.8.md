# 1.10.8 · 情境动作与气泡外观

- 语音输入改为应用播放通道静音，继续暂停助手白噪音；不再写入系统总音量、设备静音或麦克风增益，避免设备音量提示遮挡听写胶囊。结束、取消、异常及进程退出恢复应用通道原有音量与静音状态。
- 新增 Rive 咖啡、水杯、掩手哈欠、告别挥手、音乐转身动作。生活提示携带对应动作；翻译退出显示告别；音乐间隔 25–55 秒偶尔整圈旋转，耳机与音符跟随同一转向并带出短暂流光，不发出新通知、不替换歌词；录音和提醒可打断，减少动效时不随机转身。
- 双击顶部气泡空白处显示外观调节，键盘聚焦气泡后 F2 也可打开。底色与控件背景透明度单独调整，不影响文字；日夜切换、自定义文字色值和文字透明度自动保存。夜间精灵有柔和微光。
- 对话气泡、展开卡片和堆叠层均无边框；堆叠仍保留区分前后的阴影。面板接入原生点击区域及悬停保护。
- 顶部精灵、气泡与工作台栏目合并为一个设置区域；主动提醒与提示音分开，模型配置归入模型，音乐连接去掉重复播放卡片。
- 修复倒计时结束时旧气泡访问已清空状态造成的界面更新异常。

验证：Rive 编译与检查通过；Windows 原生音频模拟测试验证静音不改音量、轮询不重复写入、恢复原状态；后台浏览器验证外观调节、保存、无边框、窄窗口、原生命中区域、悬停与气泡堆叠切换。未在验证中操作用户的真实音量、剪贴板或麦克风。
