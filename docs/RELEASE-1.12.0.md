# 斐墨 1.12.0

- 日程快捷工具改为月历，日期下展示分类配色的事项；点击日期进入按小时排列的日视图，点击事项编辑或删除。工作台日程页使用同一套月视图、日视图与编辑器，保留 Notion 同步入口。
- 手动日程支持起止时间、全天、工作 / 学习 / 实验等分类、自定义颜色、备注、多次提前提醒，以及每天、每周指定星期、每月、每年的重复规律、间隔、截止日期和次数。重复事项可只修改或删除本次，也可处理整个系列。来源服务的日程修改保存在本机。
- 新增斐墨规划大师，复用已有 DeepSeek Flash 凭据。按自然语言直接创建、修改、调整和删除日程，保留当前规划对话上下文。完整结果经批量校验后一次保存；取消、格式错误或规划期间手动改动日程时，不覆盖日历。
- 日程气泡提醒按实际发生时间运行，支持重复事项、单次调整和重启去重。
- 快捷工具新增本机高级计算器：科学函数、角度 / 弧度、阶乘、组合数、隐式乘法、存储器、历史记录等。表达式不执行 JavaScript。
- 修复快速生成超过 15 秒语音时误报“语音播放积压”并结束会话的问题。播放队列按实际播放进度维持会话，允许正常长回答；音频上下文被媒体 / 设备切换暂停后尝试恢复。极端超限仅跳过本轮播报并保留文字和会话。保留回声消除、噪声抑制、智能语义插话，不调整系统或音乐音量。
- 修复语音展开卡片中的公式：在 Markdown 解析前保留 LaTeX 标记、上下标与矩阵换行，支持行内和独立公式；长公式可横向滚动，流式未闭合或不支持的表达式保留原文。代码与金额不作为公式误解析，继续使用安全渲染。
- 完整包含 1.11.0 的单击胶囊、双击千问全双工对话、流式字幕、倾听点头、思考与打字动作，以及无眼镜的麦克风耳机形象。私人本机版和小文特别版同步更新。

验证覆盖模拟日程、真实 DeepSeek 在独立虚构日历上的创建 / 调整 / 删除、后台窄窗口界面，以及合成语音和音乐混音下的实际 AudioWorklet 长回答播放、暂停恢复与停止释放。未操作用户真实麦克风、剪贴板或系统音量；不同实体声卡与蓝牙设备的实际表现仍需使用反馈。
