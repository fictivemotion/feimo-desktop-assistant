文档编号：斐墨-通用UI设计规范  
项目名称：斐墨及后续网站、App  
文档内容：默认视觉体系、组件与交互规范  
生成日期：2026-09-30  
版本：v02

## 1. 适用与优先级

这是用户确认的后续网站和 App 默认设计。新页面和新增模块采用本规范；用户明确提出的新风格、品牌要求或项目约束优先于默认值。迁移已有项目时保持功能与信息架构，以共享组件逐步统一。

目标是清晰、舒展、轻盈：深色标题、弱化辅助信息、纯白内容卡片、低饱和状态色；一个页面围绕一件主要任务。具体尺寸是本产品约定，并非声称苹果官方指定这些数值。

## 2. 背景与 Header

所有模块共用同一 Header 背景组件，涵盖品牌、状态、主导航、页面标题和说明。使用原创春日田园油画、可见的像素半调细节；禁止给每个内容卡片重复铺满油画。

背景和文字分别分层。背景层 `aria-hidden="true"`、`pointer-events:none`；文字、控件始终在清晰前景层，不对整块 Header 使用 `filter:blur()`。

| 层 | 默认参数 | 要求 |
| --- | --- | --- |
| 油画 | `cover`、位置 `center 40%`、不透明度 0.72 | 保留顶部笔触和半调，逐渐淡出 |
| 白色遮罩 | 顶部白色 alpha 0.66，中段 0.50，底部 0 | 提高可读性，不形成白色硬切线 |
| 基础毛玻璃 | `blur(1.2px) saturate(.85)` | 保留上部纹理 |
| Progressive Blur | 重叠的 2 / 6 / 14 px 背景模糊层 | 从 Header 中下部逐步增强，每层使用渐变 mask |
| 交界延伸 | Header 下方 72 px | 延伸的是装饰背景，不移动或遮挡正文 |
| 内容底色 | `#f5f8fa` / 纯白卡片 | 与渐隐背景自然融合 |

渐进模糊不能用一整块固定 blur 加透明度替代。参考实现采用 3 个渐变蒙版层，让低、中、高强度模糊在交界处交叠；最下沿所有背景与遮罩归零。正文卡片、二级弹窗与白噪音内容区域保持纯白，不再重复油画背景。

交界验收同时覆盖滚动状态：装饰背景整体还有一层末端透明蒙版，在高度的 96% 前降到完全透明；正文在独立、更高的图层中，不能被 Header 滤镜遮挡。正文滚动离开起点后，为滚动视口的顶部设置 44 px 的透明到实色渐变，避免被裁切的白色卡片在 Header 下沿形成横向硬线。回到滚动起点立即取消正文淡出，首个标签和控件保持完整可读。高对比度模式取消滚动蒙版。

减少透明度、提高对比度时隐藏装饰层；不支持 `backdrop-filter` 时以柔和渐隐背景回退。手机布局可将延伸缩短为 48 px。不得用无限动画改变模糊半径；单个 Header 使用这一套层，避免大量卡片重复高成本滤镜。

实现：[feimo-design.css](../renderer/shared/feimo-design.css)。结构示例：

```html
<header class="feimo-progressive-header">
  <div class="feimo-header-art" aria-hidden="true">
    <span class="feimo-blur-layer blur-soft"></span>
    <span class="feimo-blur-layer blur-medium"></span>
    <span class="feimo-blur-layer blur-deep"></span>
  </div>
  <!-- 品牌、导航、标题；不参与模糊 -->
</header>
```

接入其他项目时复制样式和合法油画素材，并设置 `--feimo-header-image` 的实际路径。背景允许溢出 Header，但由最外层圆角窗口裁切；内容与背景不创建相互遮挡的可点击层。

## 3. 字体与信息层级

- 字体统一为 **HarmonyOS Sans SC / HarmonyOS Sans**；未安装时回退 Microsoft YaHei UI、system-ui、sans-serif。不要混用展示字体或把图片当文字。网页如需随包分发字体，先确认许可；不要依赖用户本机绝对路径。
- 页面标题：22–28 px、700–750、行高 1.25，`#1b242d`。移动端优先 22–24 px；桌面紧凑工作台当前采用 22 px。
- 卡片标题：16–20 px、650–700，行高 1.4。
- 正文：14–16 px，行高 1.65–1.85；紧凑桌面工具允许 13 px。
- 辅助说明：12–13 px，`#63707b`；时间戳、来源、附件数量：11–12 px、`#87939d`。小字不能承载核心操作或唯一错误说明。
- 阅读内容通过 Markdown / 富文本安全渲染，支持选中、复制、段落、列表和必要的公式。持续输出不闪烁、不清空已显示内容。

## 4. 色彩

| Token | 默认值 | 用途 |
| --- | --- | --- |
| `--feimo-ink` | `#1b242d` | 标题、主操作、主要图标 |
| `--feimo-secondary` | `#63707b` | 说明与次级控件 |
| `--feimo-muted` | `#87939d` | 非关键元信息 |
| `--feimo-surface` | `#fff` | 内容卡片、快捷卡片 |
| `--feimo-canvas` | `#f5f8fa` | 页面底色 |
| `--feimo-control` | `#eaf0f4` | 控件组与输入底色 |

一个稳定的深灰主色；标签、状态以轻色背景区分身份。任务色点允许多个柔和颜色，但不把整个按钮染成高饱和色。错误、完成、暂停同时显示文字或图标，不只依靠颜色。常规正文以至少 4.5:1 对比度为目标；元信息弱化不等于不可读。

## 5. 圆角与边缘

| 组件 | 圆角 |
| --- | --- |
| 微型内部标记 | 4 px |
| 紧凑身份标签 | 6 px |
| 按钮、输入、选项 | 8 px |
| 分段控件组、导航容器 | 12 px |
| 内容卡片 | 16 px |
| 桌面工作台窗口 | 18 px |
| 快捷二级编辑卡片 | 21 px |
| 气泡、计时胶囊、底部快捷对话 | 999 px 或高度的一半 |
| 弧形工具按钮 | 50% |

同类控件固定用一个 token，不能按页面随意改变。圆形、胶囊是明确的形状例外，不能给普通卡片套大胶囊角。必要分隔线可使用 1 px 的浅灰内部线；**悬浮工具、气泡、快捷对话、倒计时小组件、二级卡片不添加外部阴影或矩形底纹**。透明原生窗口要同时关闭系统阴影，窗口背景透明；只裁切可见组件，不使用会产生台阶锯齿的整数像素区域代替圆角抗锯齿。

## 6. 间距与单一任务界面

采用 4 px 节奏：4 / 8 / 12 / 16 / 20 / 24 / 32。卡片 padding 默认 20–24 px，紧凑工具 14–16 px；相邻卡片间距 16 px，控件组内 8–12 px。标题与说明 6–8 px，说明与操作组 16–20 px。

主要操作贴近其结果区域；复制结果位于结果下方，不能放在很长页面的最底部。长功能用清晰子页签分组，避免把所有表单和统计堆在一个视口。正文支持滚动，Header 不挤压到正文无法阅读。长标签截断但保留 title 或详情入口；长知识卡片标题最多三行，正文仍完整展示。

## 7. 图标、控件与反馈

使用 **Reicon Filled**，统一 16 / 20 / 24 px；不得混用 emoji、无关符号和描边图标替代功能图标。装饰标记不占主操作焦点；纯图标按钮提供准确的 aria-label / 提示文字。

网页和移动 App 主操作触控区域推荐至少 44×44 px。紧凑桌面可见圆按钮 28–32 px，但保留合适命中范围与键盘入口。选中、悬停、禁用、加载、错误状态要齐全。AI 请求立即显示状态，再流式显示内容；错误说明区分语言包、图片内容、桥接进程和超时。

## 8. 斐墨悬浮布局

- 宠物中心是弧形工具轨道圆心；工具向左上分布，从宠物中心依次弹出，间距紧凑，支持滚轮翻组。
- 底部快捷输入居中对齐宠物，宽度不超过宠物与工具整体占用宽度，距离贴近；工具、输入、气泡、计时和编辑卡片互相避让。
- 气泡位于上方，通过小圆点连接；短内容自适应长度，普通问候每行最多约 15 个汉字。问候离开立即收起，主动通知和回答依其交互生命周期处理。
- 屏幕边缘和角落按可用空间整体重排，不能只把某个元素硬夹到窗口边缘。计时组件有关闭入口，关闭显示与停止计时分开表达。
- 普通回复气泡、弧形工具与输入采用同一浅白材质，无阴影；不再使用导致灰色矩形底纹的透明窗口滤镜。

## 9. 动效

按钮反馈 120–180 ms，卡片 / 气泡进入 180–240 ms，弧形展开与翻页 240–320 ms。默认缓动 `cubic-bezier(.2,.8,.2,1)`；工具逐个延迟约 40–60 ms。以 transform 与 opacity 为主，不循环改变布局尺寸。

气泡从下方淡入、向上淡出；分段回答保留可切换的叠层，切换时位置与透明度连续过渡。减少动效设置下取消位移、弹簧与循环动效，但保留状态提示和可操作入口。

## 10. 验收

至少检查桌面与窄窗口、滚动、长标题、空状态、加载、错误、键盘焦点、减少动效 / 透明度；桌宠额外检查四个屏幕角落。Header 交界无硬线，像素纹理上清下柔，正文始终清晰。所有弹层无重叠、无外部灰框，圆角抗锯齿正常；同类字体、圆角、图标一致。截图使用虚构数据，禁止把真实账号、密钥、私密任务带进公开文档。
