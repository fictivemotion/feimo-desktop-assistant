## 私人分发

私人安装包额外包含既有接口配置、六项已保存凭据及学习账号身份，首次使用时在目标电脑重新加密保存。既有电脑的配置与凭据予以保留。自带独立 OCR 可执行程序、RapidOCR / SLANet-plus / LaTeX-OCR 模型与依赖，无需安装 Python 或下载模型。

该私人包可访问原账户服务，仅供本人电脑使用；封装不阻止持有安装包的人读取凭据。私人数据不写入源码仓库，不进入公开安装包。公开包不携带上述配置、密钥、账户或模型资源。
